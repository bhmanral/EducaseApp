## Objective
The objective of this project is to validate the application's functionality, identify defects, and ensure a smooth user experience by executing detailed manual test cases.

## What is Manual Testing?
Manual testing is a software testing process in which test cases are executed manually without using automation tools. The tester verifies the application's functionality, user interface, navigation, validations, and overall user experience to identify defects and ensure the application behaves as expected.

## Application Details
- Application: Educase Android App
- Test Design Technique: Functional, UI, Validation, Navigation, Negative & Usability Testing

## Modules Tested
- Splash Screen
- Language Selection
- School Selection
- Home Page
- About Us
- Gallery
- Latest News
- Enquiry
- Centers
- Profile
- Contact

## Test Case Structure
The repository includes a detailed Excel test case document containing:
- Test Case ID
- Test Scenario
- Preconditions
- Test Steps
- Expected Result
- Actual Result
- Status
- Comments

## Bugs Identified
Some of the issues identified during testing include:
- Slow loading of home page and gallery images
- Partial language translation after language selection
- News images not opening
- Missing descriptions in several news articles
- Admission enquiry branch selection issue
- Incorrect map location opened by the Get Direction feature
- Broken or incorrect social media links
- Missing location preview image on the Contact page
